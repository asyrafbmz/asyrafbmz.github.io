01 / The project

Built around the way
I use my desktop.

I wanted a JARVIS-style environment that I could actually use for my projects. It brings an AI assistant with access to my computer together with a file workspace, model previews and a terminal.

Files & documents

Browse local folders and view documents inside the workspace, with the assistant available beside the active file.

CAD previews

Inspect 3D models in the workspace. The STL view brings together model information, shading options and orientation controls.

An integrated terminal

Access PowerShell, Command Prompt and Antigravity from the terminal panel while keeping the workspace in view.

An assistant that can act

Antigravity can create and edit local files and run commands on the computer. Requests can also open desktop widgets, such as the radio player shown above.

What I built

My work focuses on the custom interface and how the desktop tools fit together. Google Antigravity supplies the AI and the ability to act on the computer. JARVIS brings these capabilities into a custom desktop workspace through PowerShell.

Install the desktop application, then sign in to Antigravity through PowerShell to connect the AI assistant.

Antigravity installation docs ↗

  1. Extract the package

    Right-click JARVIS_Installation_Package.zip and choose Extract All. Open the extracted folder before running the installer.

  2. Run the installer

    Open Install-JARVIS.bat and follow its prompts for prerequisites and application setup. Printer configuration is optional.

  3. Sign in to Antigravity

    Open a new PowerShell window, enter the command below and press Enter. Complete sign-in if prompted; an existing authenticated session may be reused.

    PS >agy

    If agy is not recognised, check the CLI installation and reopen PowerShell to refresh its environment.

    Official installation and sign-in instructions ↗

  4. Open JARVIS

    Launch JARVIS using the shortcut created by the installer. Allow its local service to start before using the desktop interface.

  5. Configure printers Optional

    If your package includes printer integration, run Configure-Printers.bat and follow the prompts for your device. You can revisit the configuration later.

03 / Troubleshooting

Need a hand?

Start with these checks if the application does not open as expected.

PowerShell does not recognise “agy”

Close and reopen PowerShell after installing Antigravity. If it still fails, follow the official CLI installation instructions and confirm the command works there before launching JARVIS.

The interface shows “connection refused”

The local application service may not have started. If included in your package, run Debug-JARVIS.bat from the installation folder and inspect the error shown. This is more useful than repeatedly refreshing the page.

The interface opens, but the AI does not respond

Run agy directly in PowerShell to check sign-in, account access, available usage credits and connectivity. Once it works there, restart JARVIS and try again.

How do I change my printer configuration?

For packages with printer integration, use Configure-Printers.bat. If provided, Test-JARVIS.bat can help check the runtime and connected devices.
