Pi AutoPrint is a personal Raspberry Pi project that creates scheduled, two-page printer documents: an existing printer test sheet followed by a compact report with weather, network activity and motorcycle maintenance information.

What's in the report

Three data sources. One clear page.

Each report is built shortly before a scheduled print, using information needed for a personal household and motorcycle overview.

Weather outlook

Current local conditions and seven consecutive dated forecast days, including temperatures, forecast descriptions and rain probability.

Pi-hole activity

Local DNS request totals, blocking statistics and operational health, with the measurement period stated clearly.

Motorcycle records

Selected fuel and maintenance costs, mileage, servicing thresholds, and upcoming renewal dates from a designated Google spreadsheet.

The workflow

Built for a scheduled print, not a public dashboard.

The project uses Python on a Raspberry Pi, a local Pi-hole installation and a connected printer. Its website is only an informational page; it does not display live data or accept Google logins.

Schedule
1st, 11th and 21st of each month at 6:00 AM Singapore time.
Output
Two A4 pages within one printer job: unchanged test page, then the generated information report.
Google access
Read-only Google Sheets OAuth scope, used for the designated motorcycle reporting spreadsheet.
Storage

Privacy by design

Public explanation. Private records.

The purpose of this site is to transparently explain the personal automation and its Google Sheets authorisation, not to expose its reports or the underlying spreadsheet.

See the full privacy policy →

About the Google permission. The OAuth scope spreadsheets.readonly grants read access to spreadsheets available to the authorising Google account. Pi AutoPrint is configured to request values needed from the designated reporting spreadsheet only. It cannot edit Google Sheets through this scope.

No public Google sign-in, spreadsheet viewer or account management feature is implemented on these pages. The private Raspberry Pi runs the actual automation.
