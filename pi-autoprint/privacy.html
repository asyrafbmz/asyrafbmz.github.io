Privacy Policy

How Pi AutoPrint accesses and uses data to generate a local, scheduled printer report - and what the public website does not do.

Effective date: 1 November 2026   |   Operator: Mohamad Asyraf Bin Mohamad Zailani

Contents1. Overview2. Google data access3. How data is used4. Storage and retention5. Sharing and third parties6. Security7. Control and deletion8. Public website9. Updates and contact

1. Overview and scope

Pi AutoPrint is a personal automation project operated by Mohamad Asyraf Bin Mohamad Zailani. It runs on a privately administered Raspberry Pi and generates scheduled, two-page PDF print jobs. One page is an existing printer test sheet. The second page summarises weather forecasts, local Pi-hole activity, and selected motorcycle maintenance and spending information.

This website is informational only. It does not host the underlying spreadsheet, expose generated reports, provide a public login, or offer a service for other users to connect their accounts. This policy describes the intended handling of data in the local automation and on these informational web pages.

2. Google account and spreadsheet access

With permission from the Google account holder, Pi AutoPrint uses the Google Sheets API to obtain selected values for its motorcycle report.

Requested Google OAuth scope: https://www.googleapis.com/auth/spreadsheets.readonly. This scope allows an authorised application to read Google Sheets spreadsheets accessible to that Google account. It does not grant permission to edit spreadsheets. Although the Google permission is broad, this application is designed to request data only from its configured motorcycle reporting spreadsheet.

The categories of spreadsheet values needed for report generation are:

  • Fuel spending, maintenance and repair spending, and calculated monthly running-cost figures.
  • Recorded odometer readings, service dates, and next servicing thresholds.
  • Vehicle-related renewal and inspection dates, such as road tax, insurance and season parking expiry.

The report does not require chassis numbers, engine numbers, insurance policy numbers, personal passwords or other unrelated fields. The application is not intended to retrieve or print these values. It does not write back to, modify or delete the Google Sheet.

3. How the information is used

Authorised spreadsheet values are read for the purpose of calculating, formatting and presenting the motorcycle section of a private printable report. The application may compare dates to the current Singapore local date, calculate remaining days and kilometres, and identify approaching maintenance deadlines.

Other report components use separate sources: a public weather forecasting service for a configured locality (currently Woodlands, Singapore), and locally accessible Pi-hole statistics for DNS activity. The report is formatted into a PDF, submitted to the configured printer, and may be stored in a local archive. Google Sheets information is not used for advertising, public profiling, analytics services, or sale.

4. Local storage and retention

The Raspberry Pi may store the OAuth desktop client configuration, authorisation and refresh tokens, configuration files, cached data used during temporary service failures, archived PDF reports, logs, and print job state. The report archives and caches can include derived values from Google Sheets.

These files are intended to remain on the private Raspberry Pi and any local backups configured by its operator. Report and log retention depends on the device's archive rotation and manual housekeeping settings; a fixed automatic deletion period is not promised here.

Printing creates physical paper copies that contain selected report values. Anyone who can access those copies may see the printed information, so they should be stored or disposed of securely.

5. Sharing and third-party services

Pi AutoPrint does not sell or knowingly provide Google Sheets data to advertisers, data brokers or other external users. Google Sheets data is retrieved through Google's official API and is processed for the local reporting function. Weather requests go to the configured forecast provider; they contain a forecast location and normal network request information, not Google spreadsheet contents.

The public informational pages are hosted through GitHub Pages, which may process standard visitor request metadata under GitHub's own privacy practices. This website does not embed the private reports or Google tokens. If configured by the operator, local infrastructure, backups, printer hardware and the physical pages themselves may process or contain report data as part of operating the system.

Any disclosures required by law or to respond to a genuine security incident would be limited to what is necessary and legally permitted. Access to Google user data is not transferred for unrelated purposes.

6. Security measures and limitations

The intended implementation stores OAuth credentials and tokens in restricted local files, requests Google Sheets data over encrypted HTTPS connections, and keeps sensitive settings out of public source code and the public website. The report is produced and printed within the operator's own environment.

No internet-connected device or authentication system can guarantee absolute security. The operator is responsible for keeping the Raspberry Pi, Google account, printer, backup files and local network protected and up to date.

7. Your choices, revocation and deletion

The Google account holder controls whether to grant OAuth permission. Authorisation can be revoked using the Google Account's third-party connections/security settings. Revoking the permission prevents future authorised Sheets API reads until access is granted again; it does not automatically erase previously saved PDFs, cached values or printed pages.

To stop the local reporting activity completely, the operator can disable the scheduled print task and remove the locally saved OAuth credentials, cached data, generated PDFs and log files. Any existing paper copies should also be securely disposed of. For assistance with access or deletion, contact the developer using the address below.

8. This informational website

These Pi AutoPrint pages are static HTML and CSS. They do not provide an authentication form, run visitor tracking scripts, intentionally set cookies or collect spreadsheet values. Visiting the site does not authorise the local application to access your Google Account. Ordinary web hosting and browser processes can still create technical logs or browser cache records outside this site's control.

9. Policy updates and contact

This policy may be revised if the application's data access, processing, storage or sharing practices change. Material changes should be disclosed before the changed handling of Google user data takes place, and further consent sought where required. The effective date above identifies this version.
